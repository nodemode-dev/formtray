Shape the board

  1. Choose Edit, then drag a tile to reorder it.
  2. The corner buttons change a tile's size or remove it.
  3. Add apps, a group or the FormPortal updates tile below the board.
  4. Focus a tile and press Alt with an arrow key to move it from the keyboard.
